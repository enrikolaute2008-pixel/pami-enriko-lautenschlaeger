# StickerSmash — Assets

Este diretório deve conter os seguintes arquivos de imagem
baixados do tutorial oficial da Expo:

https://docs.expo.dev/static/images/tutorial/sticker-smash-assets.zip

Após descompactar o arquivo, copie os seguintes arquivos para assets/images/:

- background-image.png   (imagem de fundo da tela principal)
- emoji1.png             (sticker emoji 1)
- emoji2.png             (sticker emoji 2)
- emoji3.png             (sticker emoji 3)
- emoji4.png             (sticker emoji 4)
- emoji5.png             (sticker emoji 5)
- emoji6.png             (sticker emoji 6)
- icon.png               (ícone do app — 1024x1024px)
- splash-icon.png        (imagem da splash screen)
- adaptive-icon.png      (ícone adaptativo Android)
- favicon.png            (favicon web)
